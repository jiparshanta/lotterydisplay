Quick set

Type slot → Tab → game number → Enter. The slot advances automatically so you can load tickets one after another.

Current Texas scratch-off games

Tap a game to put it in the Quick set box. Images for all of these are saved in tickets/.

Bulk entry

One line per slot. Either just game numbers in slot order, or slot, game, price. Example:
2551 ⏎ 2580 …  or  1, 2551, 10 ⏎ 2, 2580, 5

Ticket images

For each game number the display looks for an image in this order: (1) an image uploaded here, (2) each source below with {game} replaced by the game number. Put your own files in the tickets/ folder named like 2551.jpg.

Upload one or many images — each file must be named after its game number (e.g. 2551.png).
